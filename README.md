UC4: Reservation Confirmation & Room Allocation

Goal: Enable Admin to confirm bookings and allocate unique room IDs.

Description:  
Admin processes requests from the queue, checks availability, and assigns unique room IDs 
to confirmed reservations. Inventory is updated atomically to prevent double-booking. Guests 
receive a confirmed reservation with a unique identifier, simulating the issuance of a booking 
confirmation in real hotels. UC4 ensures reliability and accountability in the booking process, 
bridging the gap between guest requests and actual room allocation.
