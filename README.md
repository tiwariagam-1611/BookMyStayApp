UC3: Booking Request Queue

Goal: Allow Guests to place booking requests in an ordered queue.

Description:  
Guests submit booking requests that are stored in a queue structure. 
Requests remain pending until processed by Admin, ensuring fairness and order. 
This separation of responsibilities reflects real hotel workflows, where guests 
request rooms but staff must validate and confirm availability before finalizing. 
UC3 introduces the concept of deferred processing, ensuring that multiple requests 
can be handled systematically without conflicts.
