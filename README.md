UC5: Add-On Service Selection

Goal: Allow Guests to enrich bookings with optional services.

Description:  
During booking requests, Guests can select add-on services such 
as Breakfast, Spa, or Airport Pickup. These services are attached 
to reservations and displayed upon confirmation. UC5 enhances the 
guest experience by offering personalized services, reflecting how 
hotels upsell additional amenities to improve satisfaction and revenue. 
It introduces flexibility and customization into the booking flow, making 
each reservation more tailored to guest needs.
