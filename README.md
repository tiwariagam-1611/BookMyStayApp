UC1: Room Inventory Setup
Goal: Establish the hotel’s inventory system.
Description:  
In this use case, the Admin defines the backbone of the hotel’s operations by creating room categories (Single, Double, Suite),
assigning availability counts, and setting base prices. This ensures that the system has a structured catalog of rooms before 
any guest interaction. Without UC1, no bookings can be processed, as inventory is the foundation for all subsequent flows. 
It mirrors the real-world process of hotels setting up their room database before opening for reservations.
